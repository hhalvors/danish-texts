%  2. WHAT IS TRANSCRIBED, AND HOW
%  ---------------------------------------------------------------
%  Diplomatic.  19th-century orthography exactly as printed: Philosophie,
%  Ideelæren, Charakteer, høiere, aa, capitalised nouns.  Printer's errors
%  are transcribed AS PRINTED, logged in a % comment at the site, and never
%  silently corrected -- including those the author himself lists on the
%  Rettelser leaf (§5).  Balance counts therefore drift off zero on
%  purpose; the running total is in RESUME-NOTES.md.
%
%  TYPEFACE.  ANTIQUA, like the 1869 Bidrag and unlike the Fraktur
%  det-religioese and svar-nielsen: upright roman throughout, no long s, no
%  Fraktur letterforms.  No sans-serif anywhere in the book -- the display
%  line of the part title page is a bold CONDENSED SERIFED roman, not the
%  grotesque used on the 1869 sibling's title page.  Section and chapter
%  heads use a bold display fount; the divisional ornament under a head is
%  a short centred hairline, while the ornament on the two title pages is a
%  DOUBLE rule (two parallel hairlines).
%
%  ITALIC IS USED FOR THREE THINGS, and none of them is emphasis:
%    (a) GREEK.  The book's Greek fount is a cursive; every Greek word is
%        wrapped \gk{} (see the preamble).
%    (b) the Forord's dateline, "Kjøbenhavn, den 30te Mai 1873."
%    (c) THE RUN-IN ENUMERATORS OF THE ELEATIC SECTION -- "a." (p. 33),
%        "b." (p. 34), "c." (p. 37).  Found by the pp. 33--44 batch and
%        CONFIRMED IN THE CALLING CONVERSATION at 600 dpi: the p. 33 "a."
%        is a sloped single-storey cursive sort, plainly not the upright
%        double-storey roman "a" beside it on the same line.  Set
%        \textit{}, and grep the file for ITALIC-ENUM to find every site.
%        THIS IS AN OPEN QUESTION, NOT A SETTLED RULE: §2's enumerators
%        ("a. Thales" and its fellows) are roman, and p. 39 prints "4."
%        where "d." is meant, so the section may be set from a different
%        case altogether.  All four sites want one adjudication together
%        once the book is further on.
%  LATIN AND OTHER FOREIGN MATTER IS SET UPRIGHT, in the same roman as the
%  Danish -- ratio, Stob. Ecl. phys., Metaph. VII, 7 were all read on the
%  image.  Do NOT wrap foreign matter in \textit{}; wrap it in \emph{} only
%  where it is letterspaced in the print.
%
%  EMPHASIS IS LETTERSPACING (Sperrsatz), and it is heavy in this book.
%  Set \emph{}.  spacing.py detects it mechanically; runs of flagged words
%  are reliable, and single-word flags are real more often here than in the
%  1869 sibling, but every flag is confirmed on the image.
%
%  QUOTATION MARKS ARE GUILLEMETS, «...», pointing INWARD.  The book has no
%  low-high „...“ at all.  Ten quotations were read on the image (printed
%  13, 55, 67, 88, 188, 231, 272) and every one opens « and closes »; no
%  reversed »...« pair was found in this part, unlike the 1869 sibling.
%  That is a sample of ten out of some fifty-seven, not a census: read
%  every guillemet and set what is printed, and expect the balance to drift
%  if a reversed pair does turn up.
%
%  DASHES.  Measured at 600 dpi (1:1; body 10 pt, one em ~ 83 px) on
%  printed 10, 202 and 225: hyphens 41--45 px, dashes 66--88 px, the dash
%  population one broad cluster from 0.8 to 1.05 em with nothing at an en
%  (~42 px) that is not a hyphen.  THE SCAN DOES NOT ESTABLISH A SEPARATE
%  EN-DASH SORT (PLAYBOOK §2 rule 1), so every dash is set ---.
%
%  THE «ɔ:» MARK is present (printed 135, 213, read on the image).  Both
%  OCR witnesses mangle it, so its true count is unknown and every page
%  must be read for it.
%
%  «ë» IS REAL ORTHOGRAPHY here -- Ikosaëdret, Dodekaëdret, Oktaëdret
%  (printed 30, 120) -- not OCR damage.
%
%  FOOTNOTES.  The mark is *) and ONLY ONE LEVEL IS USED in this part: the
%  Google layer has 30 occurrences of *) and none of **) or ***), and no
%  page carries two notes.  The note fount is a smaller upright roman, not
%  bold (the 1-bit binarisation makes it look bold in a render).  The
%  separator rule is left-flush and is not transcribed.  Sixteen pages
%  carry a note -- printed 25, 26, 28, 55, 59, 78, 79, 93, 101, 115, 146,
%  150, 156, 177, 195, 213 -- from a sweep of the bottom third of all 274
%  pages, cross-checked against the Google layer's inventory; the two
%  methods agree exactly.
%
%  THE ACCENT FAULTS ARE REAL AND ARE TRANSCRIBED AS PRINTED.  The Greek
%  compositor sets a grave for an acute and an acute for a grave often
%  enough that it is a habit, not an accident -- τοὺτων and τοῦς (p. 27),
%  ἀρχαὶ, τό and πέραινον (p. 28), πὰντα (p. 56) -- and BOTH OCR WITNESSES
%  SILENTLY NORMALISE EVERY ONE of them.  So the witnesses cannot be used
%  to find these; only the image can.  Transcribed as printed and logged
%  at the site, per the editorial stance.  Wrong sorts logged so far:
%  Κύσμος for Κόσμος (p. 30, two lines after a correct one) and
%  Plilolaos's for Philolaos's (p. 29).
%
%  ONE UNCLOSED PARENTHESIS, printed 55: "(i Theætetos" never closes, and
%  the page runs five opens against four closes.  The gap where the sort
%  would be holds no type.  Transcribed as printed, so a paren-balance
%  count over this book will run short by one.
%
%  NOT TRANSCRIBED: sheet signatures; the left-flush footnote separator;
%  the HathiTrust/Google furniture burnt into the page image (a grey strip
%  in the left margin and a "Digitized by Google | Original from HARVARD
%  UNIVERSITY" footer band, both of which the OCR reads); and all
%  manuscript matter (§6).
%
%  ---------------------------------------------------------------
%  3. THE INDHOLD AND THE CHAPTER HEADS GENUINELY DISAGREE
%  ---------------------------------------------------------------
%  Systematically, and the disagreement is a datum, not an error to be
%  normalised.  THE INDHOLD prints "Kapitel:" followed by a colon and sets

%
%  CHAPTER HEADS DO NOT FALL AT THE TOP OF A PAGE.  Printed 21, 65, 81,
%  195, 255 and 258 all open with running text and the head arrives partway

%    * "Første Hovedafsnit." (p. 11) and the chapter SUBTITLES are the

%    * "Den græske Philosophie." (p. 11) is bold AND letterspaced.
%    * "Første Kapitel." (p. 21) is BOLD (0.500) and NOT letterspaced.

%      ABOVE and none below, and are not letterspaced.

%  A DIVISIONAL RULE CAN STAND WITH NO HEAD AFTER IT.  Three so far: mid

%  49 and of 51.  Do not infer a missing head from a rule.
%
%  A PRINTED SECTION HEAD CAN DISAGREE WITH THE INDHOLD, beyond the

%  4. GREEK
%  ---------------------------------------------------------------
%  8194 Greek characters on 163 of the 274 pages of this part -- the Greek
