# Source dossiers

A dossier collects the passages in which one word occurs, across several
authors, from this collection's transcriptions and from *Søren Kierkegaards
Skrifter*. Each one is a directory here:

```
texts/dossiers/<word>/
  selection.txt    YOU EDIT: the recipe, the criterion, and the list of passages
  intro.texfrag    YOU EDIT (optional): LaTeX put at the head of the document
  dossier.tex      GENERATED from the two files above; never edit it
  dossier.pdf      GENERATED by make; linked from catalog.yaml
```

## Everyday use

1. Edit `selection.txt` or `intro.texfrag`.
2. Run `make` in the repo root (or `publish-danish.sh`, which runs `make`).

`make` sees that `selection.txt` or `intro.texfrag` is newer than `dossier.tex`,
regenerates `dossier.tex` with `python3 dossier.py texts/dossiers/<word>`, then
compiles `dossier.pdf` with lualatex. `make dossiers` regenerates every dossier
even when nothing here changed — use it after a transcription the dossier
quotes has been corrected and sks-search re-indexed.

## selection.txt

```
#% query: tilegn*                                    <- the recipe: FTS5 query,
#% authors: sibbern,kierkegaard,brochner,hoeffding   <- catalog.yaml author ids, in order,
#% title: Tilegnelse                                 <- and the word for the title page
#: Selected for relevance to ...                     <- '#:' lines: the printed criterion
# any other comment                                  <- ignored
AE:187                                               <- one passage reference per line
sibbern/erkjendelse:49
```

A reference is the first part of the citation that sks-search prints for a
passage: `AE:187` for SKS, `NB14:80` for a journal entry, `Papir 260:260:3`
for a paper, `sibbern/erkjendelse:49` for one of our transcriptions. Delete a
line to drop a passage; add one to include it.

To see every candidate passage, not just the selected ones, run the script
without a selection and read the result:

```
python3 dossier.py 'tilegn*' --authors sibbern,kierkegaard,brochner,hoeffding \
    --title Tilegnelse -o /tmp/everything.tex
```

(Write it outside the repo: `make` would try to build any `.tex` under `texts/`.)
Each passage there ends with a `% ...` comment whose first part is its reference.

## intro.texfrag

Plain LaTeX body text — no preamble, no `\begin{document}`. It is placed after
the title and before "About this dossier", inside an English-language block.
Start it with a `\section{...}` of your own if you want a heading. It is named
`.texfrag`, not `.tex`, because `make` tries to compile every `.tex` under `texts/`.

## Starting a new dossier

1. `mkdir texts/dossiers/<word>` and write a `selection.txt` with the three `#%`
   recipe lines and your `#:` criterion.
2. Generate the full list (as above), read it, and put the references you want
   into `selection.txt`.
3. `make`.
4. Add an entry under `dossiers:` in `catalog.yaml` (same fields as
   `references:`; copy the `tilegnelse` entry), then `python3 validate-catalog.py`.
5. `publish-danish.sh "message"` from `~/hhalvors.github.io`.

The website side needs nothing: `DanishTexts.hs` renders every `dossiers:`
entry as a "Source dossiers" section, linking to the PDF.

## What it needs

- **sks-search** (<https://github.com/hhalvors/sks-search>), cloned at
  `~/sks-search` (or set `SKS_SEARCH` to where it is). `dossier.py` runs its
  `dossier` command.
- **Its index must include this repo's transcriptions.** Build it with
  ```
  cd ~/sks-search
  SKS_TEXTS=~/danish-texts/texts ./sks_search.py index
  ```
  and rebuild it after transcriptions change. The SKS text itself comes from
  <https://github.com/kb-dk/SKS_tei>; `SKS_TEI` must point at its `data/v1.9`
  (sks-search's README explains). If the index lacks an author's
  transcriptions, or a reference in `selection.txt` is no longer found,
  `dossier.py` stops with a message rather than silently dropping passages.
- **Python 3 with PyYAML** (it reads `catalog.yaml` for authors' names and works' dates).
- **LuaLaTeX** with Libertinus, as for the rest of the repo.

## E-books

`dossier.py --ebooks` adds passages from privately held e-book reissues. Those
editions are in copyright, so the script refuses `--ebooks` for any output
inside this repo. A private copy with them is made by hand, elsewhere:

```
python3 dossier.py texts/dossiers/tilegnelse --ebooks -o ~/research/tilegnelse-dossier/tilegnelse-udvalg.tex
```

Selection references to e-books (`hoeffding/...(epub):N`) are simply skipped
in the public build.
